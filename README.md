# 🌾 Harvest Prediction ML

A machine learning project for predicting harvest dates using environmental and agricultural data.

## 🧠 About

This project focuses on building a machine learning model that predicts
harvest dates based on collected features such as weather, vegetation
indices and other environmental factors.

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost / LightGBM
- Machine Learning

## 🔄 Workflow

Data → Preprocessing → Feature Engineering → Model Training → Prediction

## 🎯 Goal

To develop a model capable of estimating harvest dates from
environmental and agricultural features.
